DIL PROGRAMI — SERVIS CALISTIRMA KOMUTLARI
==========================================

Not: Proje kokundeki .env dosyasi gerekli (dil-programi/.env)
MongoDB yerelde calisiyor olmali (mongodb://localhost:27017)
Qdrant yerelde calisiyor olmali (http://localhost:6333) — Topic Speak tekrar soru kontrolu
AI servisi (port 8001) kelime/zaman/okuyucu uretimi icin acik olmali
DASHSCOPE_API_KEY .env dosyasinda tanimli olmali (sk- ile baslar)
DASHSCOPE_API_BASE=https://dashscope-intl.aliyuncs.com/compatible-mode/v1
DASHSCOPE_HTTP_BASE=https://dashscope-intl.aliyuncs.com/api/v1
DEEPGRAM_API_KEY podcast + Topic Speak ses cevirisi icin gerekli
ffmpeg YouTube ses cikarimi icin kurulu olmali (brew install ffmpeg)


ILK KURULUM (bir kez)
---------------------

# Qdrant (Topic Speak — qwen embed/rerank duplicate check)
cd docker
docker compose up -d qdrant
# UI: http://localhost:6333/dashboard

# API
cd services/api
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
deactivate

# AI
cd ../ai
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
deactivate

# Voice
cd ../voice
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
deactivate

# Seed veri (ilk kurulum)
cd ../api
source .venv/bin/activate
PYTHONPATH=. python scripts/seed.py
deactivate


CALISTIRMA (her servis ayri terminal)
-------------------------------------

Terminal 1 — API (port 8000)
cd services/api
source .venv/bin/activate
uvicorn main:app --reload --port 8000

Terminal 2 — AI (port 8001)
cd services/ai
source .venv/bin/activate
uvicorn main:app --reload --port 8001

Terminal 3 — Voice Agent (LiveKit)
cd services/voice
source .venv/bin/activate
python agent.py dev
